# 发布说明规则

发布说明包含版本标题、中文变更列表和运行包 SHA-256。

- Release 标题：`Hysteria2MX {版本号}`，标签：`v{版本号}`。
- 发布前创建 `docs/releases/v{版本号}.md`，按下方格式填写正文；省略示例中的 SHA-256 行，发布流水线会根据实际运行包计算并追加。
- 只写公开的产品变化，不写部署环境、服务器操作、账号、凭据、私有地址或内部排查过程。
- 提交信息和变更说明使用中文，专业名词可用英文；不使用英文类型前缀或自动生成的英文发布说明。
- 仅推送和部署不创建标签或 Release；明确要求发布版本时才递增版本、准备说明并执行 `build.sh`。

```markdown
## Hysteria2MX {版本号}

- {变更描述1}
- {变更描述2}

SHA-256：{运行包 SHA-256}
```
